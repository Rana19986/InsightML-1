## 📌 About the Project

InsightML is an automated data analytics and business intelligence platform built with Python.

It allows users to upload CSV datasets and automatically generate statistical summaries, data quality reports, interactive charts, correlation analysis, categorical insights, date-based analysis, and conditional business KPIs.

The platform is designed to make exploratory data analysis more accessible without requiring users to write Python code.

---

## ✨ Key Features

### 📂 1. CSV Dataset Upload
- Upload CSV files.
- Automatic dataset inspection.
- Supports up to 200,000 rows.
- Supports up to 100 columns.

### 🔍 2. Data Quality Analysis
- Missing value detection.
- Duplicate row detection.
- Column data types.
- Unique value counts.
- Missing value percentages.

### 📊 3. Numeric Analysis
- Automatic numeric column detection.
- Statistical summary.
- Mean, standard deviation, minimum and maximum.
- Interactive distribution visualization.

### 🔗 4. Correlation Analysis
- Numeric feature correlation.
- Interactive correlation heatmap.
- Correlation summary table.

### 📈 5. Categorical Analysis
- Automatic categorical column detection.
- Top 15 category values.
- Interactive category charts.
- Frequency summaries.

### 📅 6. Time-Based Analysis
- Automatic date column detection.
- Records over time.
- Date-based trend visualization.

### 💼 7. Business KPI Analysis
- Revenue and sales detection.
- Total revenue calculation.
- Average revenue calculation.
- Quantity and units sold calculation when available.

### 📥 8. Downloadable Reports
- Data quality CSV report.
- Numeric summary CSV.
- Category summary CSV.
- Business KPI CSV.
- Combined text analysis report.

## ⚠️ Limitations

- CSV format is supported.
- Maximum upload size by row count: 200,000 rows.
- Maximum number of columns: 100.
- Predictive machine learning models are not included in Version 1.0.
- Business KPIs are calculated only when recognized columns are available.
